# Job Patrol — Angular Front-End

A responsive Angular front-end prototype inspired by the supplied Job Patrol UI PDF. Built with HTML templates, CSS, TypeScript, Angular standalone components, and template-driven forms.

## Included screens
- Home / hero search / job categories / latest jobs
- Find jobs with keyword, location, employment-type, and category filters
- Job detail page with save-job interaction
- Application form with CV file picker and confirmation screen
- Companies directory
- Register and login demo forms
- My applications demo page

## Run locally
1. Install Node.js (LTS) and npm.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local URL printed by Angular CLI (usually `http://localhost:4200`).

## Notes
- This is front-end only. Jobs are sample data in `src/app/app.component.ts`.
- Login, registration, and application submission are demonstration interactions; they do not persist data or connect to a backend.
- CV selection is front-end only and currently does not upload the file to a server.
- Replace the sample content and branding to match your final project requirements.
